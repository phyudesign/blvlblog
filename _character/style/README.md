# 썸네일 스타일 가이드 (기본: magazine)

참고 이미지: magazine-1.png

- 단색 배경, 글마다 색을 바꿔요. 순서: 웜 옐로 → 민트 그린 → 코랄 핑크 → 스카이 블루 → 라벤더 → 오렌지 → 라임 → 다시 처음
- 캐릭터는 거친 연필선, 화면을 크게 채우고 테두리에서 잘려도 괜찮아요
- 교묘의 미친 눈: 눈 양끝이 살짝 날카롭게, 눈동자는 상황마다 다르게 (반짝 별, 소용돌이, 하트, 동전, 불꽃, 점 눈 등)
- 위에 작은 라벨 + 양옆 가는 선 / 큰 제목 2줄(1줄 검정, 2줄 빨강), 같은 서체(아주 두꺼운 거친 고딕)
- 캐릭터가 제목 아랫부분을 살짝 가리는 잡지 표지 구성 (글자는 읽혀야 함)
