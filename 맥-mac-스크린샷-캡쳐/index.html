맥 Mac 스크린샷 화면 캡쳐 하는 방법

윈도우즈에 PrtSc 버튼이 있다면 맥에는 스크린샷 도구라는 것이 있습니다. 이것을 잘 몰라서 따로 유틸리티를 받아서 사용하거나 네이버 같은 웹서비스에서 제공하는 캡쳐 도구를 사용하는 경우가 많은데요. 알고보면 다양한 기능으로 활용도가 높은 맥 기본 도구 스크린샷에 대해서 알아보겠습니다.

Apple 홈페이지

 

맥에서 화면을 기록하는 다양한 방법


맥os에서 제공하는 스크린샷에은 전체화면을 한번에 캡쳐 하는 방법, 부분을 캡쳐하는 방법, 실행중인 프로그램만 캡쳐하는 방법 등 크게 5가지 기능이 있습니다. 그중 활용도가 높은 순으로 하나씩 알아보겠습니다.

맥에서 Shift + Command + 5 를 누르면 아래와 같은 도구 상자가 나옵니다.

윈도우 캡쳐하기

화면 일부 녹화하기

 


1. 전체 화면 캡쳐하기 스크린샷


(단축키 Command + Shift + 3 : 도구 상자 없이 전체 화면 캡쳐를 할 수 있습니다)


스크린샷 도구의 첫 번째 버튼을 누른 상태에서 맨 오른쪽 '캡쳐' 버튼을 누르면 캡쳐가 되고 디스플레이 우 하단에 섬네일 이미지가 먼저 보이고 섬네일 이미지를 더블클릭하면 스크린샷 편집 패널이 열리고 방금 캡쳐한 화면에 그림을 그리거나 글자를 넣거나 잘라 내는 등 간단한 편집을 통해 캡쳐 이미지를 조정해 내보낼 수 있습니다. 섬네일을 클릭 하지 않으면 자동으로 바탕화면에 저장됩니다.

스크린샷 섬네일 - 더블클릭하면 편집 도구로 진입(우하단)


스크린샷 편집 도구


 

2. 윈도우 캡쳐하기


(단축키 Command + Shift + 4 누른 다음 스페이스 바 : 도구 상자 없이 윈도우만 캡쳐 할 수 있습니다)


두 번째 탭을 선택하면 마우스 포인트가 카메라 모양으로 바뀝니다. 마우스 포인터가 올라간 윈도우가 하늘색으로 바뀌고 오른쪽 클릭하면 선택한 윈도우가 캡쳐됩니다.

클릭하면 하늘색으로 선택된 윈도우만 캡쳐됩니다


 

3. 화면 일부 캡쳐하기


(단축키 Command + Shift + 4 + 십자 포인터로 영역 선택 : 도구 상자 없이 일부 화면 캡쳐 가능합니다)


세 번째 탭을 누르면 프레임이 나오고 프레임 안을 잡고 움직이면 프레임을 이동시킬 수 있고 모서리를 잡고 영역 크기를 조절할 수 있습니다. 원하는 영역을 선택한후에 캡쳐를 누르면 원하는 화면을 캡쳐할 수 있습니다.

 

4. 화면 녹화 기능


전체 화면 또는 일부 화면을 선택해 동영상으로 기록합니다. 왼쪽은 전체 화면 오른쪽은 일부 화면입니다. 일부 화면은 스크린샷과 동일한 방식으로 기록 화면영역을 조절 할 수 있습니다. 오른족 '기록'을 누르면 동영상 녹화가 시작됩니다.

옵션을 통해 저장 위치와 타이머 마이크 등을 선택 할 수 있습니다. 이것은 스크린샷에서도 동일하게 설정 할 수 있습니다.

5. 맥북(MacBook) 터치바 스크린샷

(단축키 Command + Shift + 6 : 맥북의 터치바를 캡쳐 할 수 있습니다)

마지막으로 '시스템 설정' 사이드바에서 '키보드'를 클릭하고 오른쪽에 있는 ‘키보드 단축키’를 클릭한 다음, '스크린샷' 옵션에서 원하는 단축키로 설정 할 수있습니다.
