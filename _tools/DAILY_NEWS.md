# TCG 데일리 뉴스 작성 가이드 (매일 실행되는 예약 작업용)

블로그: https://blvlblog.com (저장소 phyudesign/blvlblog, GitHub Pages, `main`에 올리면 배포)
운영자: 슨생. 글은 한국어, 쉬운 말(응모, 당첨 메일, 한국 공식 상품명)로 써요.

## 0. 편집 원칙 (슨생, 2026-11-08) — 모든 TCG 글에 적용
사람도 구글(애드센스·검색)도 "사람이 직접 공들여 편집한 글"인지 보고 신뢰도를 매겨요. 이미지 없는 정보, 뭉뚱그린 문장은 자동 생성 글로 보이고 점수가 깎여요.
- **말하는 대상은 반드시 보여 준다:** 카드 이름이 나오면 그 카드 그림, 상품이면 박스·팩, 행사·추첨이면 공지·키비주얼. 본문에서 언급한 카드·상품마다 이미지를 찾을 때까지 찾아요(공식 특설 페이지 → 공식 카드 검색 `pokemon-card.com/card-search/resultAPI.php` → 공식 상품 페이지 → 아마존 재팬). 정말 없을 때만 슨생에게 "올려 주면 넣을 사진" 목록으로 요청.
- **세세하게, 넓게 (기본값):** 소식 하나에 이미지 하나로 끝내지 말고 관련된 것까지 찾아 넣어요. 예) 새 카드 공개 → 그 카드 + 같은 세트·같은 타입의 공식 공개 카드 묶음 + 공식 소개 영상(유튜브) + 팩·박스. 행사·팝업 → 공식 포스터·현장 사진·지도. 공식 특설 페이지의 `card/*.webp`, 공식 카드 검색 API, 공식 유튜브(【公式】ポケモンカードチャンネル·ワンピカード公式)를 먼저 뒤져요.
- **직접 못 넣는 이미지는 링크로 요청:** 공식 DB에 아직 없는 신규 공개 카드(포케카북 등 카드 리스트 사이트에만 있는 그림), 언론사 현장 사진, 실존 인물 사진 등은 직접 복사하지 않고, 끝날 때 요약에 **"슨생이 올려 주면 넣을 사진"** 목록(들어갈 자리 + 원본 페이지 링크 + 가능하면 이미지 직접 링크)을 꼭 붙여요. 본문에는 그 자리에 넣을 수 있게 비워 두지 말고 관련 공식 이미지로 먼저 채워요.
- **이미지마다 손으로 쓴 캡션:** "무슨 카드인지·번호·왜 중요한지" 한 줄 + 출처 링크. alt 에도 상품명·카드명·번호.
- **한 줄 한 줄 직접 쓴 문장:** 날짜·가격·마감은 정확한 숫자로, 블로그 운영자가 직접 확인하고 판단한 말투로("~로 보여요", "한국에서는 ~가 가장 현실적이에요"). 뻔한 서론·요약 반복·과장 금지. 교묘 말풍선은 정보에 맛을 더하는 한두 개만.
- **편집한 티가 나게:** 단락 색 박스, 핵심 숫자 굵게, 일정은 표, 관련 이전 글 링크, 같은 상품 사진을 여러 번 반복하지 않기.
- **확인되지 않은 건 쓰지 않거나 "공식 발표 전"이라고 분명히.**

## 0-1. AI로 찍어낸 글처럼 보이지 않게 (슨생, 2026-11-19) — 모든 글에 적용
구글은 "AI로 썼냐"가 아니라 **같은 틀로 찍어낸 글인지, 직접 확인·경험한 흔적이 있는지**를 봐요. 매일 같은 뼈대·같은 첫 문장이면 그것만으로 자동 생성 글처럼 보여요.
- **첫 문장을 매번 다르게:** "M월 D일 아침 TCG 소식이에요." 같은 고정 인사 금지. 그날 가장 큰 일, 독자에게 하는 질문, 어제와 달라진 점, 운영자의 한마디 등으로 바로 들어가요. 최근 5개 데일리의 첫 문장을 읽고 겹치지 않게.
- **구성을 그날 내용에 맞춰 바꾸기:** 아래 형식 중 그날 맞는 걸 고르고, **최근 3개 데일리와 같은 형식이 연달아 나오지 않게** 해요(`_posts/`에서 직전 글 h2를 확인).
  1. 게임별(포켓몬 → 원피스 → 일정표) — 소식이 고르게 많을 때
  2. 마감 순서(오늘 마감 → 이번 주 → 다음 주) — 추첨이 몰릴 때
  3. 큰 소식 하나 깊게 + 나머지 짧게 "그 밖에" — 신제품 발표·가격 인상 같은 날
  4. 질문형("한국에서 지금 바로 신청할 수 있는 건?", "이번 주 놓치면 안 되는 건?") — 정보가 실용 위주일 때
  5. 요약 상자 없이 본문으로 바로 — 소식이 2~3개뿐인 날
- **h2 이름도 돌려 쓰기:** 요약 상자(h-key)는 "오늘의 핵심"만 쓰지 말고 바쁘면 이것만 / 먼저 챙길 것 / 3줄 요약 / 요점만 등, 일정표(h-sch)는 마감 순서로 다시 보기 / 이번 주 달력 / 주말 마감표 등으로. 매일 넣을 필요도 없어요.
- **소식 제목(h3) 형식 섞기:** 전부 "상품 — 마감" 꼴로 쓰지 말고, 마감은 `<p class="when"><b>…</b></p>` 한 줄로 빼거나 질문·문장형 제목도 섞어요.
- **운영자 판단을 한두 군데:** "지난 탄이라 경쟁이 덜할 것 같아요", "개인적으로는 ○○부터 눌러 두겠어요"처럼 근거 있는 판단 문장. 단, 슨생이 직접 했다고 꾸며 쓰지 않기(직접 산 척, 당첨된 척 금지).
- **판에 박힌 AI 말투 금지:** "~에 대해 알아보겠습니다", "결론적으로", "다양한", "중요합니다", "도움이 되셨길 바랍니다", 모든 문단을 같은 길이로 쓰기, 문단마다 같은 순서(날짜→가격→결과→구매)로 나열하기. 문장 길이와 리듬을 섞어요.
- **교묘 말풍선 개수·위치도 매번 다르게** (0~2개, 늘 같은 자리 금지).
- **자동 검색 제외:** 본문(사진 캡션 제외)이 공백 빼고 1,200자 미만이면 빌드가 자동으로 noindex + 사이트맵 제외해요(`site.py` THIN_MIN). 짧은 날은 억지로 늘리지 말고 그대로 두되, 오래 읽힐 정보 글은 넉넉히 써요.

## 1. 조사 (최근 24~48시간 새 소식만)
포켓몬카드·원피스카드·**나루토카드(반다이 NARUTO 카드게임, 슨생 2026-11-15 추가)**의 **신제품 발표, 발매일, 예약·추첨·응모, 아마존 초대 요청(招待リクエスト), 재판매, 한글판 소식**을 찾아요.
- 공식: 포켓몬카드 공식(pokemon-card.com), 나루토카드 공식(naruto-cardgame.com/jp/news), 【公式】ポケモンカードチャンネル, 원피스카드 공식(onepiece-cardgame.com, en.onepiece-cardgame.com/products), 포켓몬코리아(pokemonkorea.co.kr/news/2), 포켓몬카드 한국(pokemoncard.co.kr)
- 일본 정리: 게임피디아 프리미엄(premium.gamepedia.jp/pokeca, /toreca), 스니덩 매거진(snkrdunk.com/articles), 트레카맵, アルテマ, 전격온라인·인사이드·GAME Watch
- 영어권 유통(원피스 신상 날짜가 가장 먼저 뜸): ICv2(icv2.com), 해외 판매점 발매 일정표
- 이미 블로그에 쓴 소식(최근 데일리 뉴스, `_posts/`)은 반복하지 말고 "업데이트"로만 짧게.
- 확인 안 된 루머는 쓰지 않거나 "아직 공식 발표 전"이라고 분명히 표시.
- **페이지 열람 권한 요청은 끝까지 물어봐요 (슨생 2026-11-16).** 열어야 하는 페이지가 권한 요청으로 막히면 다른 페이지로 돌아가지 말고 같은 주소로 다시 요청해요. 응답이 없어 취소되면 몇 번 더 다시 물어봐요. 끝내 못 연 페이지는 끝날 때 요약과 알림에 "못 연 페이지" 목록(주소 + 왜 필요했는지)으로 꼭 적어요.

## 2. 데일리 뉴스 글
- 파일: `_posts/tcg-데일리-YYYYMMDD.html` (한국 날짜). 맨 위 JSON 앞머리는 기존 글과 같은 형식:
  - title: `TCG 데일리 뉴스 M월 D일 — {가장 큰 소식 한 줄}`
  - slug: `tcg-데일리-YYYYMMDD`, date/mod: `YYYY-MM-DD HH:MM:SS`(한국 시간), category: `tcg`
  - **표지 시리즈 (슨생 확정 2026-11-22) — 글 종류마다 틀이 달라요.** 틀(배경 콘셉트·라벨·제목 위치)은 시리즈마다 고정, **교묘 포즈·소품·부제·앞에 놓는 상품은 매번 바꿔요.**
    | 시리즈 | 배경 틀 (`_thumbs/` 템플릿) | 라벨 / 제목 | 교묘 |
    |---|---|---|---|
    | 데일리 뉴스 | `gyomyo-series-daily-template.json` — 크레용 **신문 1면**(누런 신문지, 이중 괘선, 오른쪽 기사 칸) | 교묘 TCG 일보 / 오늘의 TCG + 빨간 부제(호외요 호외!·마감 임박!·신상 공개! 등 그날 맞게) | 신문팔이·기자·편집장 등 신문 관련 포즈를 매일 다르게 |
    | 시세·가격 글 | `gyomyo-series-price-template.json` — **칠판 시세판**(초록 칠판, 분필 화살표·차트) | 교묘의 시세판 / 시세 체크 + 노란 부제 | 안경·지시봉·계산기 등 매번 다르게 |
    | 총정리·가이드·응모 정리 | magcards 잡지형(예: `gyomyo-hadou-guide-stage.json`) | 교묘의 TCG 정보통 / 글 주제 | 글 내용에 맞는 동작 |
    | TECH | 기존 방식 | | |
    템플릿을 복사해 `_thumbs/gyomyo-daily-YYYYMMDD.json`(데일리) 등으로 만들고 `prompt` 의 Gyomyo 문장(포즈)·`eyes`·`title2` 만 바꿔 push. 나머지 합성 순서는 아래와 같아요. 신문형은 날짜 도장을 제목 오른쪽 위(`"stamp": {"text": "11월 21일", "x": 64, "y": 4, "r": 6}`), front 는 `[[54,52,100,100],[0,82,22,100]]` 부터 맞춰 봐요.
  - **본문 카드·상품 이미지에 교묘 빼꼼 (슨생 확정 2026-11-22):** 글마다 핵심 카드·상품 2~4장은 `python3 _tools/peek.py 원본 top|wave 저장.webp 위치(0~1)` 로 교묘가 카드 **뒤에 숨어 윗변을 앞발로 잡고 빼꼼** 내민 이미지로 넣어요(교묘 몸은 카드 뒤, 앞발만 카드 앞 — 카드 한가운데서 튀어나와 보이면 안 돼요). 원본은 `_thumbs/peek-src/` 에 두고(wp-content 에 두면 안 쓰는 이미지로 지워져요), 위치는 글 안에서 매번 다르게(.1~.9), top 과 wave 를 섞어 써요. 합성한 뒤 꼭 한 번 열어 보고, 교묘 몸·잘린 면이 카드 위로 보이면 다시 만들어요. alt 끝에 "— 카드 뒤에서 빼꼼 고개를 내민 교묘".
  - thumb: **슨생 확정 스타일(2026-11-08)** — 크레용 잡지 표지 배경(교묘가 오른쪽 아래에서 작게 카드 들고 '!!', 왼쪽 아래 카드 뒷면 더미) 위에 **그날 소식의 실제 카드·팩·박스를 가운데 크게** 얹고, 교묘·카드 더미는 그 앞으로. **데일리 표지 배경은 매일 새로 그려요(같은 포즈 재사용 금지, 슨생 요청 2026-11-11).** 먼저 `_thumbs/POSES.md` 를 읽고 지금까지 안 쓴 포즈(그날 소식과 어울리는 동작: 팩 뜯기, 망원경으로 살피기, 달력에 동그라미, 줄 서기, 택배 상자 열기, 메가폰으로 외치기 등)를 골라, `_thumbs/gyomyo-daily-stage-c.json` 을 복사한 `_thumbs/gyomyo-daily-YYYYMMDD.json` 의 prompt 안 `POSE:` 문장과 eyes 만 바꿔 push → GitHub '썸네일' 작업이 끝나 `_thumbs/out/gyomyo-daily-YYYYMMDD-1.png` 가 생기면(pull 하며 최대 5분 대기) 그걸 bgimg 로 써요. 만든 뒤 `_thumbs/POSES.md` 에 한 줄 추가. 배경 생성이 실패하거나 5분 넘게 안 나오면 POSES.md 에서 가장 오래전에 쓴 공용 배경(stage-1/b/c)을 쓰고 요약에 적어요. 날짜는 빨간 도장(stamp)으로. 교묘 앞 레이어 영역(front)은 배경마다 교묘 위치를 보고 맞춰요. `_thumbs/cards/daily-20261107.json` 을 복사해 `daily-YYYYMMDD.json` 으로 만들고 out(`wp-content/uploads/YYYY/MM/blvl-tcg-daily-YYYYMMDD-thumb.jpg`)·stamp 글자·items(그날 상품: 박스 누끼 `assets/products/*.webp`, 카드 `assets/cards/*.webp`)만 바꿔 `python3 _tools/thumbcard/make.py _thumbs/cards/daily-YYYYMMDD.json`. 카드·박스가 화면의 주인공, 교묘는 조연. 새 카드·박스는 배경 투명 webp 로 저장(흰 배경은 가장자리 흰색 지우기). 상품 이미지가 하나도 없을 때만 공용 표지 `/wp-content/uploads/2026/11/blvl-tcg-daily.jpg`. 일반(데일리 아닌) TCG 글은 **매번 다른 교묘 포즈**(글 내용에 맞는 동작: 돋보기로 시세 보기, 기도하며 응모, 복권 들고 점프 등, 이미 쓴 포즈와 겹치지 않게)로 같은 방식으로 `_thumbs/gyomyo-*-stage.json`(magcards 모드)에 제목을 넣어 배경을 새로 만든 뒤 합성.
  - tags: 포켓몬카드/원피스카드 등
  - desc: 오늘 소식 요약 1~2문장
- 중간 제목 색 박스(이름은 0-1처럼 매번 바꿔요): `<h2 class="h-key">요약 상자</h2>`, `<h2 class="h-pk">포켓몬카드</h2>`, `<h2 class="h-op">원피스카드</h2>`, `<h2 class="h-sch">응모·예약 일정</h2>` (다른 h2는 class 없이 = 검정 박스). 소식 제목 `<h3>` 은 자동으로 왼쪽 색 막대 박스.
- 본문 구성(예시 하나일 뿐, 0-1 형식 중에서 골라 바꿔요): 그날 상황으로 바로 들어가는 첫 문단 → 요약 상자 → `<h2>포켓몬카드</h2>` / `<h2>원피스카드</h2>` 소식별 `<h3>` + 2~4문장(날짜·가격·구성·한국에서 응모 가능 여부) → `<h2>응모·예약 일정</h2>` 표(마감 빠른 순) → 교묘 말풍선 1~2개 → 맨 아래 `참고한 곳:` 링크.
- 교묘 말풍선 형식(기존 글 참고): `<div class="emo"><img src="/wp-content/uploads/emoticons/gyomyo/{이름}.webp" ...><div class="bubble"><b>미친고양이 교묘</b>…냥</div></div>`
  이모티콘 이름: great heok happy-cards hmm-question good kyaa sob watching hmm price-check rare too-many hoho angry nyamnyam flat mine happy-sleep sounds-good lets-go blank what-now best sigh
- **이미지가 필요한 곳엔 무조건 그 이미지를 넣어요(정보 채널은 속도가 생명).** 카드 일러스트 공개 → 그 카드 이미지, 신상품 → 박스·팩 이미지, 행사·추첨 → 공지 이미지. 박스 사진만이 아니라 글에서 말하는 '그것'을 보여 줘요. 정보 카드(인포그래픽)를 만들면 카드 안에도 상품 사진을 넣고, 아직 공개 전이면 '패키지 공개 전' 칸으로 표시. 실존 인물(작가·성우 등) 사진은 직접 넣지 않아요. 대신 넣으면 좋을 사진이 있으면 끝날 때 요약에 **"슨생이 올려 주면 넣을 사진"** 목록으로 원본 페이지 링크와 들어갈 자리를 적어요(슨생이 파일을 대화에 올려 주면 그때 넣어요). 이미지는 공식 발표 페이지(pokemon-card.com/info/…, onepiece-cardgame.com/products/…)에서 찾아 아래 방법으로 받아요.
- **공식 상품 이미지도 써요(슨생 승인).** 아마존 사진이 없으면 공식 사이트(원피스카드 onepiece-cardgame.com/products, 포켓몬카드 pokemon-card.com) 상품 페이지의 박스·팩 이미지를 `_fetch/images.json` 에 `{"wp-content/uploads/YYYY/MM/blvl-이름.jpg": "원본 주소"}` 로 적고 push 한 뒤 `gh api -X POST repos/phyudesign/blvlblog/actions/workflows/fetch-images.yml/dispatches -f ref=main` (GitHub에서 받아 jpg로 저장·커밋). 글에는 그 jpg 를 쓰고 '사진 출처: ○○ 공식 사이트' + 링크를 꼭 달아요.
- **상품 소식마다(`<h3>` 하나마다) 그 상품의 아마존 재팬 박스 사진을 `<h3>` 바로 아래에 꼭 넣어요.** 사진 주소는 `monitor.py` 의 `AMZ_IMG`(ASIN→이미지 키)를 먼저 쓰고, 없으면 아마존 상품 페이지에서 찾아 `AMZ_IMG` 에도 추가. 아마존에 아직 없는 신상품이나 가격·일정 같은 소식은 **blvl 정보 카드 이미지**(1200px, 다크 배경, 상품별 색 카드, 교묘 이모티콘, 출처 줄)를 직접 만들어 넣어요: `_tools/infocard/` 의 예시 HTML(op.html, pk.html)을 복사해 내용만 바꾸고 `REPO` 를 저장소 경로로 바꾼 뒤 `node r.js` 로 jpg를 만들어 `wp-content/uploads/YYYY/MM/blvl-tcg-daily-YYYYMMDD-이름.jpg` 로 저장. **사진 없는 소식은 하나도 없게.** alt 에는 상품명·발매일·가격 키워드를 넣어요(검색 노출용). 아마존 페이지가 생기면 다음 데일리에서 박스 사진으로 업데이트.
- 이미지: 박스 사진은 아마존 상품 사진만, 출처·링크 표기(기존 `파동시커-응모-총정리.html` 의 figure 형식). 공식 유튜브는 youtube-nocookie 임베드 + 출처. 다른 사이트 이미지 복사 금지.
- **새 소식이 거의 없는 날은 글을 쓰지 않아요.** (같은 내용 반복 금지 — 애드센스 품질)

## 3. LIVE(응모 판·속보)에 올리기 — 초대 요청·예약·추첨·응모가 있을 때
- **아마존 재팬 초대 요청 상품**: `_tools/monitor.py` 의 `INVITE_JP` 맨 위에 `("ASIN", "한글 상품명", "포켓몬|원피스", "")` 추가, `AMZ_IMG` 에 대표 사진 키(가능하면) 추가. 미국 아마존은 `INVITE_US`.
- **그 밖의 추첨·예약·응모(포켓몬센터, 국내판 등)**: **속보 글은 더 만들지 않아요** (2026-11-21 애드센스 '정책 위반' 반려 후 결정 — 자동으로 찍어낸 짧은 글이 직접 쓴 글보다 많았음). 대신 홈 전광판·현황판에 뜨도록 감시기 기록(state.events)에만 넣고, 내용은 데일리 글 본문에 써요.
  ```
  cd 저장소 && python3 - <<'PY'
  import sys, json, datetime; sys.path.insert(0, "_tools"); import monitor as m
  st = json.loads(m.STATE.read_text(encoding="utf-8")); now = m.NOW
  st.setdefault("events", []).insert(0, {"at": now.strftime("%m/%d %H:%M"), "ts": now.strftime("%Y-%m-%d %H:%M:%S"),
      "shop_kr": "포켓몬센터 온라인", "title": "상품명 추첨 접수 (마감 11/11)", "status": "new",
      "url": "공식 공지 주소", "price": "", "img": "", "asin": ""})
  m.STATE.write_text(json.dumps(st, ensure_ascii=False, indent=1), encoding="utf-8")
  PY
  ```
  (제목에 응모 목록 상품명(파동시커, OP-18 …)을 넣으면 전광판 카드에 그 상품 사진이 자동으로 붙어요. `/속보-…` 글 파일(`_posts/속보-*.html`)은 절대 새로 만들지 않아요.)

## 6. 인스타그램 확인 (오전 11시대 별도 예약 작업, 슨생 맥 브라우저 사용)
