유튜브를 하다 보면 하나의 채널에 다양한 컨텐츠를 게시하는 것보다 채널마다 컨셉을 구분해서 여러 채널을 운영하는 경우가 있습니다. 채널 추가를 통해 하나의 계정에 여러개의 채널을 만들어 관리할 수 있습니다. 이것을 '브랜드 계정' 이라고 하는데요. 오늘은 다양한 채널 운영을 원하는 유튜버를 위한 채널 추가 및 삭제 방법에 대해 알아보겠습니다.

 

기존 계정에 여러 채널을 추가하는 방법


일단 제가 아는 한 채널 추가는 데스크톱 브라우저에서만 가능합니다. 그래서 채널 추가는 PC에서 하시거나 혹은 모바일에서 웹 브라우저(크롬, 사파리 등)로 유튜브로 접속한 다음 데스크톱 브라우저로 보기로 바꾼 다음 채널을 추가할 수 있습니다. 채널 추가 방법은 생각보다 쉬우나 페이지를 찾기가 어려워서 헤매는 경우가 많습니다. 지금부터 빠르게 알아볼게요.

 

1. 프로필에서 '설정'으로 들어가기


유튜브 우상단 프로필 이미지를 클릭해서 '설정'으로 들어갑니다.

 

2. 계정 관리에서 '채널 추가 또는 관리' 클릭


설정 창이 열리고 계정 탭으로 자동으로 연결됩니다. 우측 패널에 있는 '새 채널 만들기'를 클릭합니다.

 

3. '채널 만들기' 클릭


채널 리스트 페이지로 이동하고 '채널 만들기' 버튼을 눌러줍니다.

 

4. 새로운 채널 정보 입력


채널 생성 페이지로 이동합니다. 원하는 채널 이름을 입력하고 채널 생성 동의 체크 후 만들기 버튼을 눌러줍니다.

 

5. 새 채널 만들기 성공!


채널 만들기에 성공하셨습니다. 채널 맞춤 설정에서 남아있는 설정을 마무리해 보세요. 세 번째 네 번째 채널도 같은 방법으로 추가할 수 있습니다.

 

유튜브 채널 삭제하는 방법


 

1. 삭제하려는 채널로 접속 후 우상단 프로필 클릭
2. 패널에서 '설정'을 클릭



 

3. 왼쪽 패널에서 '고급 설정' 들어가기
4. 오른쪽 패널 맨 아래에 '채널 삭제' 클릭


 

5. YouTube 콘텐츠 삭제 창에서 '영구 삭제' 선택


 

6-7. 확인 항목에 체크 후 '내 콘텐츠 삭제' 클릭


 

8-9. 채널 이름을 입력 후 '내 콘텐츠 삭제' 클릭


 

10. 채널이 완전히 삭제 되었습니다.


 

[보너스 팁] 모바일에서 새 채널 만드는 방법 - 크롬 버전


평소 PC를 잘 사용하지 않는 분들도 계실 텐데요. 모바일로 유튜브 채널을 생성하려면 모바일 웹브라우저를 데스크톱 브라우저로 바꿔야 하는데요 아주 간단합니다.

1. 모바일에서 크롬 브라우저를 열고 'youtube.com'으로 접속


2. 하단 옵션 버튼(...) 누르기


3. 옵션 창에서 '데스크톱 사이트로 보기' 선택

4. YouTube가 데스크톱 브라우저로 열리면 프로필 사진을 누르기

5. '설정'으로 들어가 앞서 보여드린 PC에서의 방법과 동일하게 진행하시면 됩니다
