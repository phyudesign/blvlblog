구글 애드센스 ads.txt 문제 해결 - 워드프레스

2024년 5월 3일 by blvl.

이번 포스팅에서는 워드프레스 블로그 애드센스 승인 후 "Ads.txt 파일을 찾을 수 없음" 경고가 뜨는 경우 해결법을 알려 드리겠습니다. 아주 간단하게 해결 할수 있으니까 당황하지 말고 쭉쭉 따라오세요.

 

애드센스 Ads.txt란 무엇인가?


Ads.txt는 구글에서 광고가 제대로 적용되고 개시되고 있는지 그리고 혹시 악용되고 있는 않은지 확인하기 위해 개발된 장치로 광고주가 광고를 구입하고 광고를 게시할 수 있는 웹사이트의 목록을 확인할 수 있게 해주는 파일입니다. 구글이 애드센스로 광고를 게시하고 확인하는데 중요한 역할을 하기 때문에 Ads.txt에 문제가 생기면 광고 수익 지급이 안되기 때문에 반듯이 해결해야 하는 문제입니다.

 

워드프레스에서 애드센스 Ads.txt 문제 해결 방법


1. Google Adsence 사이트에 로그인 > 사이트로 이동


2. 왼쪽 패널 내 사이트URL을 클릭


3. ads.txt 코드를 복사


4. 워드프레스 로그인 > 플러그인 > 새 플러그인 추가 > Ads.txt Manager 검색 > Ads.txt Manager 설치 및 활성화


본인이 원하는 Ads.txt 플러그인을 사용하시면 됩니다, 되도록 많은 사람들이 사용하는 검증된 플로그인을 추천합니다


5. 설정 > ads.txt > 복사한 ads.txt 코드 붙여넣고 > Save Changes


6. Google AdSence > 사이트 > 사이트 URL클릭 > 업데이트 확인


7. 사이트 탭에서 Ads.txt 승인 상태 확인


Ads.txt가 정상적으로 등록되었습니다.

(승인이 나지 않으면 5분 정도 기다렸다 다시 시도 해보세요. 실시간 크롤링이 안될 수 있습니다)
